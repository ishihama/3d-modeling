# desk-tray 仕様

## 用途

机の上に置く小物トレイ（ペン・クリップ・付箋などの仕分け）。お試し用の最初のモデル。

## 種別

実用品（build123d）

## 寸法・制約

| 項目 | 値 | 備考 |
| --- | --- | --- |
| 外形 W × D × H | 100 × 60 × 40 mm | W = 幅方向（X） |
| 肉厚（外壁・仕切り） | 2.0 mm | |
| 底面厚 | 1.6 mm | |
| 縦の角 | R4 | 外形の 4 隅（Z 方向のエッジ） |
| 区画 | 幅方向に 3 区画 | 仕切り 2 枚、区画は等幅 |
| 仕切り高さ | 外壁より 5 mm 低い（上端 = 35 mm） | |

## 形状の要件

- 箱形トレイ、上面開放
- 幅方向（X）に 3 区画、仕切りは奥行方向（Y）に外壁から外壁まで
- 底面外周 0.5 mm 面取り
- 上端（外壁・仕切りの上面エッジ）R1

## 材料・色

- 材料: PLA
- 色: 任意
- サポート: 無し
- 2 ノズル使用: 無し

## 対象年齢

大人向け（子供向けおもちゃではない）
