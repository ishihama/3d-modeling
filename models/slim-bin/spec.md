# slim-bin 仕様

## 用途

洗面所・トイレに置く薄型のゴミ箱。綿棒・コットン・ティッシュなどの小さなゴミ用。
ゴミ袋はかけず、中身をそのまま捨てて本体を洗う。

## 種別

実用品（build123d）。3 パーツ構成: 本体 body / 蓋フレーム lid / スイングフラップ flap

### 実装で決めた補助寸法

| 項目 | 値 | 理由 |
| --- | --- | --- |
| 軸の高さ | 本体底から 156.0 mm | 軸受け穴の上端と天板下面の間に 1.1 mm の肉 |
| 耳（軸を支える板） | 厚さ 3.0（X）、幅 6（Y）、上端 R3 | 回転時に天板に当たらない大きさ（投入口の幅内に収まる） |
| 軸受けブロック | 6（X）× 14（Y）、天板裏から 6.6 mm 下がる | 耳との隙間 1.0 mm。軸のかかり 3 mm |
| 軸受けの溝 | 上から 半円 R2.9 → 直線 0.4 → 45° の返し → 入口 幅 4.6 × 長さ 1.0 → 45° の呼び込み 1.0 | 入口は軸径 −0.4（スナップ）。直線 0.4 は、軸が返しに乗ったときに穴の中心に来る長さ |
| 蓋フレーム天板の縁 | 外周・投入口とも 45° 面取り 1.0 | 印刷時はベッド側になるため R ではなく面取り（エレファントフット対策も兼ねる） |
| 本体上端 | R0.99 | 肉厚 2.0 の両縁 R1 は OCC のフィレットが失敗するため（desk-tray と同じ） |
| フラップ | 上面の縁 R1、下面の縁 0.5 面取り | |

## 形状の要件

- 本体は上に向かって広がる台形（オーバーハングなし・外に倒れる向きなので造形は安定）
- 蓋フレームは本体の上端にかぶせるだけ（固定しない。持ち上げて外し、中身を捨てる）
- フラップは中心軸で回転し、押すとどちら向きにも回ってゴミが落ち、手を離すと自重で水平に戻る
  - フラップは投入口より 4.5〜7.5 mm 下（本体の内側）に収まる
  - ±90° まで回しても本体・蓋フレームと干渉しないことを確認済み
- フラップの軸は、蓋フレーム裏側の軸受けに下から押し込んではめる（入口を軸径より 0.4 mm 狭くしたスナップ。PETG のしなりを使う）
- 底面外周 0.5 mm 面取り、上向きエッジ R1 以上
- 各パーツ単体でサポート無しで印刷できる向き
  - 本体: 底を下
  - 蓋フレーム: 天板を下（逆さ）。軸受けの返しは 45° で造形できる
  - フラップ: 平らな面を下
- **許容した例外**: フラップの軸（直径 5 × 長さ 4 mm の片持ち）の下側に、45° を超える小さなオーバーハングが残る（約 33 mm²、表面積の 0.26%）。
  涙滴形の軸は先端が回転時に軸受けの入口の角に当たるため使えない。この大きさの軸はサポート無しで造形できる範囲として許容する。
  - check_stl の層ごとの解析では、軸の最初の層（フラップ下面から 5.1 mm）が「片持ちの張り出し 4.0 mm」として **WARN** になる（ERROR は 5 mm 超）。上記の理由で許容

## 材料・色

- 材料: **PETG**（水回りの湿気、フラップ軸のスナップ・回転の粘りが必要なため）
- 色: 未定
- サポート: 無し
- 2 ノズル使用: 無し

## 対象年齢

大人向け（子供向けおもちゃではない）

## 組み立て

1. 蓋フレームを裏返し、フラップの 2 本の軸を軸受けの溝に下から押し込む（パチンとはまる）
2. 蓋フレームを本体にかぶせる
