# profiles/

Bambu Studio のプロファイル（プロセス・フィラメント・プリンタ）をエクスポートして置く場所。

- ファイル名例: `process-0.20mm-standard-x2d.json`, `filament-pla-basic.json`, `filament-petg-hf.json`
- Bambu Studio の「エクスポート → プリセット」で書き出したものをそのまま置く
- プロファイルを変更したら、その理由を下の表に追記する
- 既定値は CLAUDE.md の設計ルール（ノズル 0.4 mm・積層 0.2 mm・PLA 既定）に揃える
- アカウント情報・プリンタのアクセスコード・シリアル番号など機密は含めないこと
